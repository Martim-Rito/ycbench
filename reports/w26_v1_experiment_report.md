# W26 Dataset v1: first exploratory experiment

_Generated by `scripts/run_w26_v1_experiment.py`. Early-checkpoint exploration: two plain Logistic Regressions, no tuning._

## 1. Data used

- `data/processed/w26_dataset_v1.csv`, rows with `target_defined == 1`: **198** startups, **20** positives (`target_top20 = 1`), 178 negatives. Target unchanged (prevalence 0.101).
- Model A: `founder_n_founders`, `founder_previous_yc`, `company_one_liner_n_words`.
- Model B: Model A + `log1p(attn_google_mentions_pre_raw)` (the only transformation).
- Not used: `company_site_tld_group` (no categorical encoding yet), `ref_baseline_top20`, `ref_attn_google_mentions_pre_cleaned_nb` (reference only).

The missing rows are 5 startups, the same for all three columns: arzule, ishikilabs, noetic, resonate, scout-out (0 of them positive). **[F]** They are the CSV-only startups with no `yc_all_companies.json` record. `attn_google_mentions_pre_raw` has no missing values here.

## 3. Imputation and model

- Numeric columns: median; `founder_previous_yc` (binary): most frequent value. Both are fitted on the training fold only, inside an sklearn `Pipeline` (imputer -> LogisticRegression), so nothing leaks from the test fold.
- `LogisticRegression(random_state=0)`, all other parameters sklearn defaults (L2, C=1, lbfgs, max_iter=100). No class weights, no scaling, no tuning. Convergence warnings: Model A 0, Model B 0 (over 50 fits each).

## 4. Cross-validation

- `RepeatedStratifiedKFold`: 5 folds x 10 repeats (50 fits), `random_state=0`; both models use identical splits.
- Precision / recall / F1 use the default 0.5 probability threshold (no threshold optimisation; zero_division = 0). ROC-AUC and PR-AUC (average precision) are computed per test fold. Cells are mean ± SD over the 50 folds.

### OOF Top-20 hits

Each repeat gives one out-of-fold probability for every one of the 198 startups; the top 20 by that probability are compared with `target_top20`. Mean ± SD (and min-max) over the 10 repeats. Ties at the rank-20 boundary are broken by slug order for the deterministic count; the 'expected' row averages over random tie-breaking, which matters when the model gives few distinct probabilities.

| | Reference baseline | Model A | Model B |
|---|---|---|---|
| OOF Top-20 hits (deterministic ties) | 14/20 (not a model) | 3.300 ± 0.823 (min 2, max 4) | 2.100 ± 0.568 (min 1, max 3) |
| OOF Top-20 hits (expected under random ties) | | 3.23 | 2.10 |
| rows tied at the boundary probability (mean over repeats) | | 1.5 | 1.0 |
| OOF ROC-AUC over all 198 (mean over repeats) | | 0.537 | 0.619 |
| OOF average precision over all 198 (mean over repeats) | | 0.134 | 0.142 |

A random top-20 would recover about 2.0 of the 20 positives. The baseline is the published/reproduced YC Bench overlap (`ref_baseline_top20` ∩ `target_top20`, computed by `scripts/build_w26_dataset.py`); it is shown for context and is **not** the YC Bench Precision@20 protocol, so the numbers are not strictly comparable.

## 6. Interpretation

- **Model A (no attention) carries at most a very weak signal.** Mean fold ROC-AUC 0.57 (SD 0.13 across folds), OOF Top-20 hits 3.3 (range 2-4) against about 2.0 for chance. That is above chance on average but well inside the fold-to-fold spread with 4 positives per test fold, so it should not be read as evidence of signal.
- **Model B (+ log1p raw attention) does not recover the ranking either.** Mean fold ROC-AUC 0.64, OOF Top-20 hits 2.1, i.e. chance level, far from the 14/20 of the reference baseline. Adding attention raised the AUC by about 0.08 but did not improve the Top-20 count or PR-AUC.
- **Threshold metrics are uninformative here.** With a 10% base rate, no balancing and weak features, the models almost never exceed 0.5 (0.02 predicted positives per fold), so precision, recall and F1 are 0 by construction. The ranking metrics are the ones to read.
- **[I] Why raw attention is so far from the baseline (not tested here):** the baseline uses the researcher-curated cleaned counts (`ref_attn_google_mentions_pre_cleaned_nb`), whereas the raw counts are extremely heavy-tailed (up to 2.6e8), plausibly inflated for domains that collide with common words. A monotone log1p on those counts keeps that noise. This is a hypothesis about a data-quality difference, not a result.
- Net: the three simple non-attention features give no demonstrable signal for Top-20 at this sample size, and raw attention as encoded here adds little. The comparison with the 14/20 baseline is context only.

## 7. Caveats

- 20 positives: every metric has wide uncertainty. The ± values are the spread over CV folds/repeats, not a confidence interval for the population; repeats reuse the same 198 startups, so they understate it.
- The target is dominated by 11 startups covered by one hand-entered article plus 9 attention-driven positives (see `reports/w26_dataset_report.md`, section 5). Traction is unobserved for most startups, so the computed Pre-Demo Score may underestimate the score that would be obtained with complete traction coverage.
- `attn_google_mentions_pre_raw` comes from the same Google / domain measurement channel as the target, was retrieved after the cutoff, and is nonzero for some domains registered after it. Model B therefore measures how much that channel adds, not a clean point-in-time signal.
- `company_one_liner_n_words` and the founder features come from 2026 snapshots; `founder_previous_yc` is 1 for only 5 of the 193 rows with a value and none of them is a positive, so its coefficient is driven by a handful of rows.
- No scaling, so coefficient magnitudes are not comparable across features; coefficients are not interpreted here.
- Imputation affects 5 rows (median/mode). The Top-20 count is a single ranking statistic and does not follow the YC Bench evaluation protocol exactly.
